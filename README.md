# Магазин портативных гаджетов (Portative Shop)

## Описание проекта
Данный проект представляет собой веб-приложение на базе фреймворка Django, эмулирующее структуру интернет-магазина портативной техники и аксессуаров. В качестве референса и источника тематики каталога использовался интернет-магазин [Portative.by](https://portative.by/). 

Приложение содержит базовую настройку проекта, конфигурацию часового пояса и языкового кода, а также функционал отображения текстовых страниц через стандартные HTTP-ответы без использования HTML-шаблонов.

## Список страниц магазина
На текущем этапе разработки в приложении реализованы 3 текстовые страницы:

1. **Главная страница (`/`)** — стартовая точка приложения. Содержит приветствие и plain-text ссылки (URL-пути) для перехода на информационные разделы.
2. **О магазине (`/about/`)** — страница с описанием сути разработанного магазина, его тематики (гаджеты, аксессуары, умный дом) и основных направлений работы.
3. **Об авторе (`/author/`)** — персональная страница создателя лабораторной работы, содержащая информацию о студенте, группе и назначении проекта.

## Инструкция по запуску
1. Установите зависимости: `pip install -r requirements.txt` (или `pip install django`).
2. Выполните миграции: `python manage.py migrate`.
3. Запустите сервер разработки: `python manage.py runserver`.
4. Перейдите по адресу `http://127.0.0` в браузере.
